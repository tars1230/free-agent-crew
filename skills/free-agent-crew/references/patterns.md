# 多员工协作范式

1. **并行复核 + 共识**：`crew review` → 只采纳 ≥2 人同意或带具体证据的问题。
2. **脑暴 → 收敛**：`crew brainstorm` 拿去重后的 Top 10，再用 `crew review` 让员工挑刺你选中的 1–2 个。
3. **接力**：`crew relay` 三段（起草 → 挑错改进 → 定稿），某段失败自动交给下一个员工。
4. **做-审分离**：`crew cross --write` 一人改、其余人审；你最后看 diff 决定是否保留。
5. **你做 + 员工审**：完成后 `crew review "审查 <diff 或文件>"`，员工意见是参考不是命令。

任务写法要点：给目标、范围（文件/目录）、输出格式（例如"每条给 file:line + 证据 + 修法"、"首行裁决词"）。可直接复制的模板见安装目录 `{{CREW_HOME}}/app/prompts/`。
