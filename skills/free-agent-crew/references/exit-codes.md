# 退出码

| 码 | 含义 | 你该做什么 |
|---|---|---|
| 0 | 至少一个员工完成（汇总见输出） | 阅读并**自己判断**结论 |
| 75 | 所有员工达标的免费模型额度暂时用尽，或没有模型达到能力门槛 | 不要重试；把输出里的"最早恢复时间"/被排除原因告诉用户，或改为自己完成 |
| 78 | 判断类调用（复核/验收等）没有可用的生产级模型，按规则不退到弱模型 | 不要改用弱模型重试；换有生产级模型的员工或生产级工具（如 cursor-agent / agy）复核 |
| 124 | 总时限到或长时间无输出 | 缩小任务或加大 `--timeout` 后最多再试一次 |
| 127 | 员工 CLI 未安装 | `crew setup` |
| 77 | 需要登录 | 请用户执行提示中的登录命令（如 `cline auth`） |
| 64 | 用法错误 | `crew help` |
| 其他 | 员工 CLI 自身错误 | 看输出末尾和 `{{CREW_HOME}}/logs/<员工>.log` |
